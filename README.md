## 🎨 Core Visual & Functional Innovations

1. **Frosted Aurora & Champagne Gold Design System**: Built with premium HSL variables, fluid glassmorphic containers (`backdrop-filter: blur(25px)`), customized typography, and high-fidelity micro-interactions.
2. **Interactive AI Neural Flow Sandbox**: Allows users to input custom reviews in real time to observe spelling normalization, NLP sentiment mapping, and vector path particle routing into respective domain buckets.
3. **Data Cleaner Laser Scanner**: A beautiful, glowing green scanning grid that sweeps cards dynamically to simulate active multi-layer deduplication.
4. **Scroll-Triggered Graph Animations**: Charts trigger rendering sequences via `IntersectionObserver` when entering the viewport. Area trend graphs draw curves dynamically, and bar charts rise up from the baseline over a smooth 1.5s transition.
5. **Ledger Hover Helper Cat**: A 3D-shaded mascot guide that tracks hover coordinates in the Standardized Customer Ledger, reading reviews alongside the user and reacting with context-aware expressions.

## 📊 Analytical Pipeline Architecture

AetherInsight operates a 5-phase sandboxed pipeline:

```
[ RAW FILE / DRAG & DROP ] (Phase 1)
           │
           ▼
[ CSV/JSON LINE READERS ] ➔ Quote-aware tokenizer maps headers and lines.
           │
           ▼
[ FUZZY DEDUPLICATOR ] (Phase 2) ➔ Calculates Levenshtein Distance to merge typo duplicates.
           │
           ▼
[ ATTRIBUTE INFERENCING ] ➔ Keyword-token parser auto-fills missing categories.
           │
           ▼
[ NLP LEXICON SCORING ] ➔ Lexicon scans score sentiments from -1.0 (Critical) to +1.0 (Praise).
           │
           ▼
[ 2D VECTOR CLUSTERING ] (Phase 3) ➔ Groups similar review coordinates using sin/cos scattering.
           │
           ▼
[ ANOMALY RADAR ] ➔ Flags warning indicators if negative support spikes occur on single dates.
           │
           ▼
[ LEDGER & EXECUTIVE DASHBOARD ] (Phases 4 & 5) ➔ Renders area waves, volume bars, and hotfixes.
```

## ⚙️ AI Tools & Algorithmic Methods

- **Fuzzy Matching**: Custom `Levenshtein Edit-Distance` checks string transformations to combine matching profiles (e.g., merging "John Smit" and "John Smith" if changes $\le 2$).
- **NLP Classifier**: Keyword-to-sector token parser matching categories dynamically (*"battery", "drain"* ➔ Battery & Hardware).
- **Sentiment Lexicon**: Counts matching sentiment tokens to rate overall customer satisfaction.
- **Trigonometric Coordinate Dispersion**: Uses seed offsets (`Math.sin` and `Math.cos`) to group node coordinate coordinates visually into clusters without overlap.

## 🛠️ Technology Stack & Selection Rationale

- **React 19 & Vite 8**: Selected for reactive interface adjustments, state hooks orchestration, and fast dev compilation cycles (**1.2s** compilation).
- **CSS3 (Luxe HSL styling)**: Omitted template utilities (like Tailwind) for total layout controls and visual uniqueness.
- **Recharts (D3 Engines)**: Implements native SVG path rendering for timeline wave area charts and volume bars.
- **HTML5 FileReader**: Allows local spreadsheet file parsing (`.csv`, `.json`, `.txt`) entirely in the client-side memory, ensuring **100% database privacy and security** with zero backend latency.

## 🚀 Setup & Launch Instructions

### **Prerequisites**
- **Node.js**: `v18.x` or higher
- **Package Manager**: `npm`

### **1. Install Dependencies**
Navigate to the root directory and install node packages:
```bash
npm install
```

### **2. Launch Development Server**
Run the local Vite server:
```bash
npm run dev
```
Open **`http://localhost:5173`** in your browser.

### **3. Compile Production Bundle**
Verify code correctness and bundle size:
```bash
npm run build
```
